# EduSync — Smart Campus Management System

A full-stack campus management app with student/faculty dashboards, AI-based face attendance, resource sharing, and e-library.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```
   npm install
   ```
2. Run the app:
   ```
   npm run dev
   ```

No API keys required. The app runs on local mock data.
